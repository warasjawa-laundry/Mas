## Integritas dan keamanan

Hash member/kartu/event/nominal lama sama sebelum dan sesudah patch; nilai historis tidak dibackfill. Harga, ongkir dan durasi memakai katalog/snapshot database. Owner tetap memakai UUID Owner sendiri; kasir memerlukan dua token aktif, current permission dan outlet scope setiap RPC.

Advisor Production saat diperiksa: 32 INFO RLS tanpa policy (default deny), 4 WARN executable SECURITY DEFINER untuk anon, 11 untuk authenticated, dan WARN leaked-password protection disabled. RPC terpapar tetap memeriksa Owner atau token/grant; guard kontak private tidak mempunyai execute grant aplikasi. Role/revoke/negative tests QA tersedia, tetapi risiko known-ID impersonation MAS-XXXX tetap belum terselesaikan. Tidak menyatakan advisor bersih atau login ID-only kuat.
