2. UAT login Owner dan Kasir MAS-XXXX di Android nyata + revoke/timeout + kamera/galeri QR, barcode: **BELUM TERUJI**.
3. Source POS Owner baru hanya bisa pratinjau nota. Belum ada owner-actor CREATE_ORDER/PAYMENT/WORK/REFUND berizin dan diaudit pada G4/G5. Menggunakan token kasir untuk Owner **dilarang**. `ownerPosWriteUat` tetap FALSE.
